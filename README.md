# 📊 Sales Analytics Dashboard

A professional sales analytics dashboard built with Python, Pandas, Plotly, and Streamlit.

## 🎯 Project Goal
Analyze the Superstore Sales Dataset and build an interactive dashboard
to uncover key business insights.

## 🛠️ Tools Used
- **Python** — Core programming language
- **Pandas** — Data manipulation and cleaning
- **Plotly** — Interactive charts and visualizations
- **Streamlit** — Dashboard framework
- **NumPy** — Forecasting calculations
- **Jupyter Notebook** — Data exploration and cleaning

## 📊 Dashboard Features
- **Overview** — KPIs, Sales & Profit summary
- **Sales Analysis** — Monthly trends, category & product analysis
- **Profit Analysis** — Profit trends, discount impact
- **Forecast Analysis** — 6-month sales forecast
- **Customer Segmentation** — Segment breakdown
- **Geographical Map** — State-level sales distribution
- **Business Insights** — Data-driven recommendations
- **Conclusion** — Project summary

## 🔍 Key Findings
- Identified most profitable regions and categories
- Analysed impact of discounts on profit margins
- Forecasted future sales trends
- Provided actionable business recommendations

## 🚀 How to Run Locally
```bash
# Clone the repository
git clone https://github.com/desolami/Sales-Dashboard-Project.git

# Navigate to Dashboard folder
cd Sales-Dashboard-Project/Dashboard

# Install dependencies
pip install -r requirements.txt

# Run the dashboard
streamlit run app.py
```
